# VeriVoice Official Signup & Credential Dashboard Links

## Overview
Direct official URLs for registering accounts and generating free API credentials required for live VeriVoice testing.

---

### 1. Groq Cloud API (STT & LLM Verification)
- **Purpose**: Ultra-fast Whisper STT audio transcription and Llama 3.3 70B verification.
- **Account Required**: Free Groq Account
- **Official Signup**: [https://console.groq.com/signup](https://console.groq.com/signup)
- **Developer Dashboard**: [https://console.groq.com/keys](https://console.groq.com/keys)
- **Credential Obtained**: `GROQ_API_KEY`
- **Free Tier**: Yes (Generous free rate limits)
- **Payment Required**: **NO**

---

### 2. Meta WhatsApp Cloud API (WhatsApp Voice Messaging)
- **Purpose**: Send & receive WhatsApp voice notes and webhook events.
- **Account Required**: Free Meta Developer Account
- **Official Signup**: [https://developers.facebook.com/](https://developers.facebook.com/)
- **Developer Dashboard**: [https://developers.facebook.com/apps/](https://developers.facebook.com/apps/)
- **Credentials Obtained**: `WHATSAPP_TOKEN`, `WHATSAPP_PHONE_NUMBER_ID`
- **Free Tier**: Yes (1,000 free conversation sessions per month)
- **Payment Required**: **NO**

---

### 3. Render (Free Cloud Backend Hosting)
- **Purpose**: Deploy Express backend to a public HTTPS endpoint for Meta webhooks.
- **Account Required**: Free Render Account
- **Official Signup**: [https://dashboard.render.com/register](https://dashboard.render.com/register)
- **Developer Dashboard**: [https://dashboard.render.com/](https://dashboard.render.com/)
- **Free Tier**: Yes (Free Web Service tier)
- **Payment Required**: **NO**

---

### 4. ngrok (Local Public HTTPS Tunnel for Testing)
- **Purpose**: Expose local localhost:3000 to a temporary public HTTPS URL for instant webhook testing.
- **Account Required**: Free ngrok Account
- **Official Signup**: [https://dashboard.ngrok.com/signup](https://dashboard.ngrok.com/signup)
- **Developer Dashboard**: [https://dashboard.ngrok.com/get-started/your-authtoken](https://dashboard.ngrok.com/get-started/your-authtoken)
- **Free Tier**: Yes
- **Payment Required**: **NO**

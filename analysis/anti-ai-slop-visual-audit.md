## 2. Key Changes by Area

### 2.1 Removed Elements (Subtraction over Decoration)
* ❌ Removed repeated card containers wrapping every single section.
* ❌ Removed nested card-in-card patterns in Talk and Chat.
* ❌ Removed unearned decorative badges and "AI-powered" buzzwords.
* ❌ Removed heavy rectangular container borders, replacing them with subtle hairline dividers (`border-white/[0.06]`).

### 2.2 New 3D Component: Evidence Constellation (`EvidenceConstellation3D.tsx`)
* Built a sub-millisecond, mathematical HTML5 Canvas 3D perspective projection component.
* Projects primary institutional authorities (WHO, NASA, CDC, WMO, NDMA) orbiting in 3D depth space around the central user claim.
* Interactive mouse parallax tilt adds subtle architectural depth without heavy WebGL engine dependencies.

### 2.3 Typography & Hierarchy
* **Literata (Editorial Display Serif)**: Used for authoritative headlines, key narrative moments, and verified truth statements.
* **Inter (Modern Neutral Sans)**: Used for interface controls, body paragraphs, and dialogue text.
* **JetBrains Mono (Technical Monospace)**: Restrained strictly to small authority chips, timestamps, and confidence percentages.
* **Noto Naskh Arabic**: Native `1.9` line-height handling for Urdu in RTL mode (`[dir="rtl"]`).

### 2.4 Thematic Color Restraint
* **Deep Charcoal Canvas (`#0E0E0E`)**: Baseline dominant tone.
* **Midnight Navy Atmosphere (`#12141A`)**: Used for full-bleed section tone shifts.
* **VeriVoice Teal (`#2E5A5A` / `#7ED4D6`)**: Used strictly for active voice states, interactive links, and verification moments.
* **Warm Off-White (`#FBF9F3`)**: Primary editorial typography.
